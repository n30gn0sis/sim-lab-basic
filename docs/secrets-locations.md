# Secrets — by location, never by value

**Date:** 2026-09-14

Every credential the kit needs is generated **on the R770**, once, under
`/etc/lab/secrets/` (directory mode 0700, files 0600, owner root), and is
printed nowhere: not on the terminal, not in the evidence transcripts, not in
git. A script that needs a value reads the file. The files below are the
complete list.

| File | Generated by | Consumed by | Contents |
|---|---|---|---|
| `/etc/lab/secrets/malcolm-admin.pw` | `r770-malcolm-deploy.sh secrets` | `auth` (hashed with `openssl passwd -1` and bcrypt via the bundled nginx-proxy image; only the hashes reach `auth_setup`) | the analyst login for Malcolm — and, through `r770-portal-deploy.sh htpasswd`, for the portal, docs |
| `/etc/lab/secrets/gns3-admin.pw` | `r770-gns3-deploy.sh secrets` | `config` (rendered into `/etc/gns3/gns3_server.conf`, mode 0600, owner `gns3`) · `r770-validate.sh --area gns3` (login test) | the GNS3 `admin` password |
| `/etc/lab/secrets/restic.pw` | Phase 15 (not this kit) | `r770-validate.sh --area backup` | the restic repository password |

Derived material that is also secret and also never in git:

| Path | What |
|---|---|
| `/etc/lab/ca/pki/private/` | the internal CA key (`ca.key`) and the server key — the PKI directory is 0700 |
| `/etc/nginx/ssl/lab.key` | the portal's server key, 0600 |
| `/opt/malcolm/malcolm/nginx/htpasswd`, `/etc/nginx/lab.htpasswd` | password hashes, 0640 (`www-data` group on the nginx copy) |
| `/opt/malcolm/malcolm/config/*.env`, keystores, forward certs | written by Malcolm's `auth_setup` |

## Rotation

Rerun the `secrets` subcommand with `--force`, then the step that consumes it:
`malcolm auth --force` (regenerates certs and keystores too), `gns3 config`
then `systemctl restart gns3`. The old value is gone the moment the file is
rewritten.

## Handing a password to an analyst

Read it from the file as root (`cat /etc/lab/secrets/malcolm-admin.pw`) and
pass it out of band. The wiki tells analysts the passwords are issued by the
operator; it never carries one.
